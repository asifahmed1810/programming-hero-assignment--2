# Project Name: FitLife

**Live Link:**  https://asifahmed1810.github.io/programming-hero-assignment--2/

FitLife is a modern fitness website designed to inspire, guide, and support individuals on their health and wellness journey. The platform provides personalized workout routines, nutrition guides, and progress tracking tools. FitLife combines sleek design with functionality to offer a seamless user experience.

## Technologies Used
- HTML 
- Tailwind CSS  
- React Toastify  

## Key Features
1. **Personalized Workout Planner**  
   Users can create customized workout routines based on their goals and fitness levels.  

2. **Progress Tracking Dashboard**  
   Interactive charts and graphs help users monitor their fitness journey effectively.  

3. **Responsive, Interactive Interface**  
   Fully responsive design ensures a smooth experience on all devices, from mobile to desktop.
